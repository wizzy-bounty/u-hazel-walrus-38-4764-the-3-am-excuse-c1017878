One line, under 200 characters: the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM.

The wallet's angle: 3 AM is when the scammers clock in and the owner's judgment clocks out — so until sunrise, it signs for no one.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is standard-library-only Python, deterministic, with no network access. It writes the single entry line to `/output/entry.txt`.
